# Polymer MS Analysis

Python tools for polymer mass spectrometry analysis 

---

## Overview

This repository contains Python software for the analysis of polymer mass spectrometry data. The code was developed to support polymer characterization through automated spectral processing

---

## Features

- Searches out polymer repeating unit from mass spectrum list  
- Finds m/z fragments corresponding to repeating units
- outputs the number of m/z fragments detected 
- integrates them and outputs the integrated intensities 

---

## Requirements

- Python 3.11+
- NumPy
- SciPy
- Pandas
- Matplotlib

Install dependencies using

```bash
pip install -r requirements.txt
```

---

## Usage

```bash
python polymer_analysis.py
```
